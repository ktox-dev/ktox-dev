### 🚀 What I'm working on

**[ktox.dev](https://ktox.dev)** · *FiveM resources*  
A line of four FiveM resources - garages, fishing, dispatch and cases - each running on ESX, QB-Core, QBox and ox_core through a single bridge file. Ships with a Next.js storefront (Tebex checkout, Discord OAuth, Neon Postgres) and a Fumadocs documentation site at [docs.ktox.dev](https://docs.ktox.dev).  
`Lua` · `TypeScript` · `Next.js` · `PostgreSQL`

**[ktx_claude_bridge](https://github.com/ktox-dev/ktx_claude_bridge)**  
HTTP bridge and MCP server connecting Claude Code to a running FiveM server - real-time Lua execution, NUI/CDP control, console capture and DB queries.  
`TypeScript` · `Lua` · `MCP`

**Homelab**  
Around twenty self-hosted services in Docker Compose stacks behind Traefik, reached through a Cloudflare Zero Trust tunnel instead of open ports, with CrowdSec filtering traffic and a Grafana/Prometheus/Loki stack alerting on the whole thing.  
`Docker` · `Traefik` · `Grafana` · `Linux`

**[pterodactyl-git-webhook](https://github.com/ktox-dev/pterodactyl-git-webhook)**  
Small Python webserver that auto-pulls and manages git submodules for Docker containers running on Pterodactyl.  
`Python` · `Docker`

**[lanis-mobile](https://github.com/lanis-mobile/lanis)** · *Open Source Contributor*  
Mobile app for "Schulportal Hessen" - the official school portal of the German state of Hesse. Built in Flutter/Dart with active users and official cooperation with the Hessian Ministry of Education.  
`Dart` · `Flutter`
